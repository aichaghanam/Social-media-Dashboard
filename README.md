#  Social Media Performance Dashboard (Power BI)

##  Project Overview

This interactive Social Media Dashboard was developed during my internship to support the management and analysis of the company’s digital presence across Instagram, Facebook, LinkedIn, and Wix.

The main objective was to centralize key performance data into a dynamic and visual reporting tool that enables clear performance tracking and data-driven decision-making.

---

##  Business Context

Managing multiple social media platforms often results in fragmented data and time-consuming reporting processes.

This dashboard was designed to:

- Consolidate performance metrics into one centralized view  
- Simplify reporting and performance tracking  
- Enable comparison between platforms  
- Identify high-performing content strategies  

---

##  Key Features

- Interactive filters (by platform, period, campaign)
- KPI cards for engagement rate, reach, impressions, and follower growth
- Trend analysis over time
- Platform comparison visuals
- Content performance breakdown
- Dynamic slicers for customized analysis

---

##  Metrics Analyzed

- Total Reach
- Impressions

- Content Interaction
