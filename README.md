This interactive Social Media Dashboard was developed during my internship to support the management and analysis of the company’s digital presence across Instagram, Facebook, LinkedIn, and Wix. The dashboard consolidates key performance metrics such as engagement rate, reach, impressions, audience growth, and content performance into a clear and dynamic reporting tool. By using filters and interactive visuals, it allows users to analyze trends over time, compare platform performance, and identify which content strategies generate the best results. This project strengthened my skills in data visualization, performance analysis, and data-driven decision-making to optimize social media strategy and improve overall digital impact.
